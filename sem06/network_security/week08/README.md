# Week 08 — Lab 5: LAN security (hardware) and STP and CAM table attacks (Packet Tracer)

**Module:** Network Security (`DFCS H3015`)  
**Semester:** 6 (Year 3), folder `sem06`

[Module README](../README.md)

## What this week is for

Lecture 8 was implementing intrusion prevention. Lab 5 is about the security of the Layer 2 infrastructure. The hardware lab (room E124) has four parts: configure basic switch settings (build the topology, set the hostname and IP address and configure SSH), configure secure trunk ports and create VLANs (trunk mode, a different native VLAN, verifying and disabling trunking), create VLANs and assign switch ports, and configure port security and disable unused ports. Part 2 is a Packet Tracer activity that follows attacks on the network: assign the Core switch as the root bridge, secure the spanning-tree parameters against STP manipulation attacks and enable port security against CAM table overflow attacks.
