# Week 04 — Labs 4 and 5: footprinting and reconnaissance, host discovery

**Module:** Professional Penetration Testing (`DFCS H3014`)  
**Semester:** 6 (Year 3), folder `sem06`

[Module README](../README.md)

## What this week is for

Lab 4 (100 minutes, 23 February 2026, submitted on 2 March) looks at a small subset of the reconnaissance tools, those listed for the PenTest+ exam: search engines and Google dorking, Shodan, whois and nslookup, theHarvester, Recon-ng, FOCA, Maltego, the OSINT Framework and additional TryHackMe rooms. Lab 5 (100 minutes) is host discovery: the ping command, fping, when to use an ARP scan, Nmap and Nmap live host discovery, and RustScan (optional).
