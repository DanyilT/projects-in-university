# Week 10 — Lab 10: privilege escalation

**Module:** Professional Penetration Testing (`DFCS H3014`)  
**Semester:** 6 (Year 3), folder `sem06`

[Module README](../README.md)

## What this week is for

Lab 10 (3 hours, 20 April 2026, submitted on 8 May) is two TryHackMe rooms on privilege escalation, which depends on the configuration of the target (the kernel version, the installed applications, the supported languages, other users' passwords): Linux PrivEsc Arena, a very vulnerable Linux VM with SSH open, and Linux Privilege Escalation, the fundamentals from enumeration to exploitation with over eight techniques. The lab page asks to understand each attack, because the steps are needed for the practical exam.
