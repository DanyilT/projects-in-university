# Week 05 — Lab 6: vulnerability scanners

**Module:** Professional Penetration Testing (`DFCS H3014`)  
**Semester:** 6 (Year 3), folder `sem06`

[Module README](../README.md)

## What this week is for

Lab 6 (360 minutes, 2 March 2026, submitted on 16 March) is a first look at vulnerability scanners, with the two most popular free options, Nessus and OpenVAS, to try both and choose one: Vulnerabilities 101 (the flaws of an application and research in vulnerability databases), setting up and using Nessus, the basics of threat and vulnerability management with OpenVAS (Greenbone), and scanning Metasploitable 1. The installation guides of Nessus and OpenVAS, and a handout for the Greenbone error "The feed owner is currently not set", are in the [resources](resources/) of this week. The Metasploitable 1 virtual machine (1.3 GB) is too big for the repository and is on [MEGA](https://mega.nz/file/fgBFgCJa#hTM2dmGni1YbDr2HXRYAcH0LPe-D6eOCLNb0fDKTnbA); all the target machines of the module are listed in [Target virtual machines](../README.md#target-virtual-machines).
