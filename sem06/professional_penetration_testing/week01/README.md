[Module README](../README.md)

## What this week is for

Lab 2 (120 minutes, 2 February 2026, submitted on 9 February) introduces TryHackMe, the platform used most weeks to supplement the labs: create an account, enrol on a learning path, complete the first three Introduction rooms (Tutorial, Starting out in Cyber Sec, Introductory Research), learn to search the rooms and decide where to go next. Lab 2a is a list of TryHackMe rooms on planning and engagement: the essential rooms are Beginner Path Intro, Starting Out in Cyber Sec, Jr Security Analyst, Pentesting Fundamentals, Hacker Methodology, Red Team Engagements, Defensive Security and Tutorial, followed by optional rooms. The getting-started slides also ask for an account on HackTheBox.
