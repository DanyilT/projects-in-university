# Week 07 — Lab 7: introduction to Metasploit

**Module:** Professional Penetration Testing (`DFCS H3014`)  
**Semester:** 6 (Year 3), folder `sem06`

[Module README](../README.md)

## What this week is for

Lab 7 (180 minutes, 16 March 2026, submitted on 23 March) is a quick introduction to Metasploit, the most widely used exploitation framework, with TryHackMe and practical walkthroughs: the Metasploit: Introduction room, a Metasploit demo against Metasploitable 1, a demo against Windows XP and using Metasploit to exploit the EternalBlue Windows vulnerability. The Metasploitable 1 lab instructions describe a penetration test against the Metasploitable 1 virtual machine from a Kali attacker machine. The two target virtual machines of the demos are too big for the repository and are on MEGA: [Metasploitable 1](https://mega.nz/file/fgBFgCJa#hTM2dmGni1YbDr2HXRYAcH0LPe-D6eOCLNb0fDKTnbA) (1.3 GB) and [Windows XP](https://mega.nz/file/mwQlySZa#raa664ugzCa7tmdCYVAA-vVbxC08SFrDHO9WZjlgbAA) (0.5 GB); all the target machines of the module are listed in [Target virtual machines](../README.md#target-virtual-machines).
