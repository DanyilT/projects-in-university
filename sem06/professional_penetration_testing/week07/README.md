[Module README](../README.md)

## What this week is for

Lab 7 (180 minutes, 16 March 2026, submitted on 23 March) is a quick introduction to Metasploit, the most widely used exploitation framework, with TryHackMe and practical walkthroughs: the Metasploit: Introduction room, a Metasploit demo against Metasploitable 1, a demo against Windows XP and using Metasploit to exploit the EternalBlue Windows vulnerability. The Metasploitable 1 lab instructions describe a penetration test against the Metasploitable 1 virtual machine from a Kali attacker machine.
