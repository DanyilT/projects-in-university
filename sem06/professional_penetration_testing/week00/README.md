# Week 00 — Lab 1: configuring the lab environment

**Module:** Professional Penetration Testing (`DFCS H3014`)  
**Semester:** 6 (Year 3), folder `sem06`

[Module README](../README.md)

## What this week is for

Lab 1 (120 minutes, 26 January 2026) sets up the lab: VirtualBox as the hypervisor and a Kali Linux virtual machine (the pre-built VirtualBox image, a 7-Zip archive that is extracted first; at least 2048 MB of RAM), which is recommended for the labs and in-class demos, although any setup can be used. The lab page says that the main assessment of the module is a large practical test in exam week, a simulated penetration test on a small company network. The report is one page, the cover page of the lab.
