# Week 08 — Lab 8: attacking passwords

**Module:** Professional Penetration Testing (`DFCS H3014`)  
**Semester:** 6 (Year 3), folder `sem06`

[Module README](../README.md)

## What this week is for

Lab 8 (3 hours, 23 March 2026, submitted on 30 March) is about attacking passwords: generating custom wordlists with Crunch, Hydra, cracking Windows and Linux password hashes, cracking Windows LM hashes and the SAM file, an introduction to Hashcat and the TryHackMe hash cracking rooms. The lab/resources folder has the files of the exercises as a zip (the Windows SAM and SYSTEM files, a Linux shadow file, an LM hash file and John the Ripper examples). The quick reference collects the commands of sections 8.4 and 8.5.
