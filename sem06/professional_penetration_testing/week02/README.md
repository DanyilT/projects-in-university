# Week 02 — Lab 2b: a simulated penetration test

**Module:** Professional Penetration Testing (`DFCS H3014`)  
**Semester:** 6 (Year 3), folder `sem06`

[Module README](../README.md)

## What this week is for

Lab 2b (180 minutes, report dated 9 February 2026) is a basic penetration test in a controlled environment, with a structured professional methodology, against a target virtual machine: reconnaissance (information gathering), service enumeration and analysis, vulnerability research, initial access, privilege escalation, and reporting and lab submission, plus an extra step. The report is a penetration test report, kept as markdown (two versions, the second with the metadata for the pandoc conversion) and as a PDF made with pandoc, with the screenshots in the img folder. The target virtual machine, Basic Pentesting 2 (a 1.4 GB VirtualBox appliance), is too big for the repository and is on [MEGA](https://mega.nz/file/y1B2RYBB#2fSzXBIqA1OvdGOvucRdeZiVDx0LYEph_FLYQfOxrSE); all the target machines of the module are listed in [Target virtual machines](../README.md#target-virtual-machines). The guide to importing an OVA file into VirtualBox is in the [resources](resources/) of this week.
