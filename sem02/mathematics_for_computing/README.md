## What this module is for

Mathematics for Computing is a second-semester module on the mathematics behind computing, including set theory. The assessments are a quiz test in week 7 (a Moodle quiz of 20 questions in 90 minutes, mixing multiple-choice questions and fill-in answers, covering all the topics to date) and a final exam on 8 May 2024. This folder has no lab sheets, notes or exam papers for the module, and this page is the only record of what it covers.
