# Week 09 — Formative worksheet: collections, composition and inheritance

**Module:** Fundamentals of Programming 2 (`COMP H1031`)  
**Semester:** 2 (Year 1), folder `sem02`

[Module README](../README.md)

## What this week is for

Formative worksheet 9: collections, composition and inheritance. A Person class, Athlete and Employee classes that extend it, and a PersonCollection that stores people in an ArrayList. The solution uses classes and inheritance. It does not use interfaces.
