# Week 02 — Lab 2: configure SSH

**Module:** Routers and Routing Basics (`COMP H1021`)  
**Semester:** 2 (Year 1), folder `sem02`

[Module README](../README.md)

## What this week is for

Lab 2 is a Packet Tracer activity on SSH. Telnet sends passwords in plain text, so the sheet secures switch S1: encrypt the passwords, set the domain name netacad.pka, generate 1024-bit RSA keys, create an admin user, allow only SSH into the VTY lines, and then check that Telnet fails and SSH works. The Packet Tracer file is listed below.
