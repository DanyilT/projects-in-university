# Week 07 — Lab 7: IPv4 static and default routes

**Module:** Routers and Routing Basics (`COMP H1021`)  
**Semester:** 2 (Year 1), folder `sem02`

[Module README](../README.md)

## What this week is for

Lab 7 is a hands-on lab on real equipment, not Packet Tracer: two routers, two switches and two PCs, joined by Ethernet and serial cables. The sheet sets the device names and interface addresses, checks connectivity, and then adds static routes: a recursive static route on R1 to the R3 LAN (192.168.1.0/24), a directly connected static route on R3 to the R1 LAN (192.168.0.0/24), routes on R1 to R3's two loopback networks, and a default route on R1 through its serial interface. The sheet has reflection questions. There is no solution file for this lab in the repository.
