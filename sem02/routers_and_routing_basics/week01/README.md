# Week 01 — Lab 1: basic switch configuration

**Module:** Routers and Routing Basics (`COMP H1021`)  
**Semester:** 2 (Year 1), folder `sem02`

[Module README](../README.md)

## What this week is for

Lab 1 is a Packet Tracer activity on the first setup of a Cisco 2960 switch. The sheet covers checking the default configuration, naming the switch S1, putting a management address on VLAN 99 (192.168.1.2/24, with an IPv6 address as well), setting a default gateway and passwords, and testing the connection with ping and Telnet. The last part works with the MAC address table: recording the PC's MAC address, looking at the addresses the switch has learned, and setting a static MAC address on port F0/6. The PDF is the instructor's copy of the lab, so its expected answers are shown in red. The Packet Tracer file is listed below.
