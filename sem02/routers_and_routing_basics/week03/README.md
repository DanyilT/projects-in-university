# Week 03 — Lab 3: configure router interfaces

**Module:** Routers and Routing Basics (`COMP H1021`)  
**Semester:** 2 (Year 1), folder `sem02`

[Module README](../README.md)

## What this week is for

Lab 3 is a Packet Tracer activity on router interfaces. R1 has the IPv4 LANs and R2 has the IPv6 LANs, and each LAN has a PC. The sheet gives an addressing table. The addresses are set on the interfaces and the PCs, and then the PCs must ping each other and the Dual Stack Server. The Packet Tracer file is listed below.
