# Week 05 — Lab 5: router-on-a-stick and password recovery

**Module:** Routers and Routing Basics (`COMP H1021`)  
**Semester:** 2 (Year 1), folder `sem02`

[Module README](../README.md)

## What this week is for

Lab 5 has two tasks. Task 1 is a Packet Tracer activity on router-on-a-stick inter-VLAN routing: VLANs 10 and 30 on switch S1, two subinterfaces on router R1 (G0/0.10 and G0/0.30, using 802.1Q), and a trunk from S1 to R1. The sheet asks why the ping from PC1 to PC3 fails before routing is set up, and which VLAN the trunk port is in. There is no Packet Tracer solution file for this task. Task 2 is a hands-on lab on real equipment, not Packet Tracer: recovering the console passwords on a Cisco router and switch. Each person sets a password on their own router and switch, then recovers the other person's. The lab shows that anyone with physical access can reach the configuration, which is why physical security matters. There is no solution file for task 2 either.
