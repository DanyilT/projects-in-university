# Personal and Professional Development

**Module:** Personal and Professional Development (`COMP H1033`)  
**Semester:** 1 (Year 1), folder `sem01`  
**Lecturer:** Maria Brennan  
**Date:** September - December 2023  
**Credits:** 5 ECTS

## What this module is for

Personal and Professional Development covers presentations, communication skills and teamwork. It starts with an extended induction in week 1 (online preparation tasks about the student union, class representatives and equality, and a quiz). The main assessment is a group presentation (free subject): report and a presentation on blockchain technology, its applications and how to hack a blockchain. Lab 5 (week 8) is a climate change report of seven pages. Week 11 is an MCQ test, which is not in the repository. This folder has the climate change report, the blockchain report and presentation (the part on hacking a blockchain and the full group version of each, with the Google Docs and Google Slides links of the full versions) and screenshots of those files.
