## What this module is for

Computer Systems is a first-year module on how computer systems work and how to use them from the command line. This folder has no files. The module has two assessments: CA 1, an in-lab practical test (disassembly and re-assembly of a PC, week 4, 10%), and CA 3, an MCQ test (week 13, 30%). Their papers are not in the repository. One usefull resource is the one-page [Unix/Linux Command Reference (PDF, FOSSwire)](https://files.fosswire.com/2007/08/fwunixref.pdf). It lists the everyday commands for files, system information, processes, permissions, networking, SSH, searching, compression and installing software, with the keyboard shortcuts.
