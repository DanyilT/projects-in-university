# Week 06 — Lab 4: analysis using Autopsy

**Module:** Computer and Network Forensics (`DFCS H3011`)  
**Semester:** 5 (Year 3), folder `sem05`

[Module README](../README.md)

## What this week is for

Lab 4 is the second investigation of the same memory stick image, with Autopsy and the Sleuth Kit: install Autopsy, get to know its features and analyse the disk image. The questions ask, for example, how many images are viewable in thumbnail mode and what the image _AF6.JPG contains when it is examined with other options, and what happens when the encrypted folder is unzipped. The answers are in two parts, as in week 5: the answers to the questions and a forensic analysis report. A second, long sheet (Lab 4.1, Autopsy Deep Dive) shows how to image a laptop and use Autopsy to analyse its contents. The reading is the Forensic Report Guidelines.
