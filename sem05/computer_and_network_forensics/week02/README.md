# Week 02 — Labs 1 and 1a: write blockers and extracting volatile data

**Module:** Computer and Network Forensics (`DFCS H3011`)  
**Semester:** 5 (Year 3), folder `sem05`

[Module README](../README.md)

## What this week is for

Lab 1 is about write blockers and the role they play in a forensic investigation; a software write blocker does not have to be created and no screenshots are needed. The sheet shows a Windows 7 machine with a restore point, writing to a USB device, blocking USB writes with Regedit, creating a REG file and taking a screenshot, and ends with four questions: why write blockers are essential, the main types of write blockers, the main challenges of write blocking and the implications of open-source write blocking (at least 300 words in total). Lab 1a, Extracting Volatile Data (Manually), explains what volatile data is and live forensics, then collects it with commands: system information, network connections, the routing configuration, the date and time, system variables, task lists (with modules and with services), workstation information, the ARP cache, the DNS configuration, network shares and the network configuration. Both labs are answered in one Word document that is uploaded by Sunday at 8 pm.
