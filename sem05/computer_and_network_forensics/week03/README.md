[Module README](../README.md)

## What this week is for

Lab 2 uses AccessData FTK Imager (version 3.4.0.5), an imaging tool that is used here for some basic analysis, on the image of a thumb drive. The case: a group of UFO enthusiasts came into possession of a thumb drive that an undercover agent had left at a dead drop after trying to destroy some of the sensitive information on it; they made an image of the drive and asked an investigative firm to examine it. The questions ask, for example, what the hex content of the image shows about the file system and what the sector count and image type of the image are. The answers are saved to a Word document and uploaded to Brightspace. A second sheet, FTK Imager to create a Duplicate, explains the tool and how it makes an exact copy of evidence. The week's readings are the ENISA guide for first responders (Lab 2.1) and An Introduction to Digital Forensics by Michael Hegarty.
