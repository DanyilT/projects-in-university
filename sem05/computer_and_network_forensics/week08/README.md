# Week 08 — Lab 5: steganography

**Module:** Computer and Network Forensics (`DFCS H3011`)  
**Semester:** 5 (Year 3), folder `sem05`

[Module README](../README.md)

## What this week is for

Lab 5 is about steganography, hiding information in a carrier file (discussed in lecture 5): four open-source steganography tools for audio and image formats are downloaded (OpenPuff is suggested), data is hidden in carrier files with each of them, and the differences are documented with hash algorithms. The documentation covers four tools, OpenPuff (GUI), Steghide (CLI), OpenStego (Java GUI) and rSteg, each with how data is embedded and extracted. The week's readings are Lest We Remember: Cold Boot Attacks on Encryption Keys, Cybercrime Legislation and the Role of Digital Forensics in Ireland by Michael Hegarty, and an AI-generated podcast on that paper.
