# Week 05 — Lab 3: analysis using FTK

**Module:** Computer and Network Forensics (`DFCS H3011`)  
**Semester:** 5 (Year 3), folder `sem05`

[Module README](../README.md)

## What this week is for

Lab 3 moves from imaging to analysis: AccessData Forensic Toolkit (FTK) is used to analyse the bit-stream image of a memory stick. The case: Steve Billings, the manager of a family-run business, has concerns about two of his employees, Martha Heiser (the distribution official, who started an urgent leave) and George Montgomery, and the digital evidence is examined. The questions begin with the case log options (the format and the use of the FTK log file) and continue through the analysis of the image. The answers are in two parts: the answers to the questions, and a forensic analysis report (case name, tool used, introduction and findings). The week's readings are a one-page forensic process overview and the Secure Hash Standard.
