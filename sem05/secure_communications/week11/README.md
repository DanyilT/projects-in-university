## What this week is for

Week 11 was a self-paced lab week: the lab sessions did not have to be attended. Section C, OpenSSL, uses OpenSSL commands to inspect live HTTPS connections (the TLS method, the key exchange, the encryption algorithm, the hashing function and the size of the public key). Section D, Examining traces, analyses the provided network trace files in Wireshark to find the TLS/SSL protocols, cipher suites, hashing methods and key lengths, and the VPN handshake details. Each section is worth 1 mark (2 in total); the PDF is uploaded to Brightspace by Sunday 30 November 2025, 23:59.
