## What this week is for

The lecture of week 10 was PGP and a deep dive into SSL/TLS. Lab 5 (Tunnelling and Web Security) investigates SSL/TLS and VPN tunnels. Section A, Web cryptography assessment, uses the SSL Labs tool on three chosen sites (the grade, the key size and type of the certificate, whether the name matches, who signed it). Section B, Viewing details, captures and examines HTTPS traffic with Wireshark and the browser tools to find the TLS versions, cipher suites, hashing methods and key lengths. Each section is worth 1 mark (2 in total); the PDF is uploaded to Brightspace by Sunday 23 November 2025, 23:59.
