# Week 12 — Course summary

**Module:** Secure Communications (`DFCS H3013`)  
**Semester:** 5 (Year 3), folder `sem05`

[Module README](../README.md)

## What this week is for

The folder has a summary of the module in one PDF: the instructor, the assessment (20% labs, 40% project, 40% in-class test) and the lectures: introduction to cryptography and classic ciphers; encoding, hashing and passwords; keys, symmetric and asymmetric encryption; key exchange and Diffie-Hellman; RSA, ECC and digital signatures; PKI, certificates and SSL/TLS; cryptanalysis and attacks; wireless security; PGP and an SSL/TLS deep dive.
