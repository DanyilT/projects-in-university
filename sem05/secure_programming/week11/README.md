## What this week is for

In this lab a static code analyser, the Snyk CLI, is used on the Coffeeshop application: a Snyk account is created, the CLI is installed (it is also available as a plugin for the main IDEs), the Coffeeshop site is scanned with snyk code test and the findings are reviewed.
