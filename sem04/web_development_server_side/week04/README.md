# Week 04 — Lab 4: build a no-frills PHP CRUD app with routing, part 1

**Module:** Web Development Server-Side (`COMP H2029`)  
**Semester:** 4 (Year 2), folder `sem04`

[Module README](../README.md)

## What this week is for

Lab 4 is part 1 of a tutorial (by Tania Rascia, adapted for the module by the lecturer) that builds a small PHP and MySQL database app: building the front end (an index page with templating, an add-a-user page and a query-users page), initialising the database and connecting to it with PDO, adding a new user (Create), with the connection script in its own file and sanitised form input, and viewing and filtering users (Read). In the module schedule the lab runs in weeks 6 and 7. The result is the first of the two commits of the matching branch [`assessment/year02/module-web_development_server_side/no-frills-php-crud-app`](https://github.com/DanyilT/projects-in-university/tree/assessment/year02/module-web_development_server_side/no-frills-php-crud-app), which adds a simple PHP CRUD app that creates and reads users, with basic routing and templates, the database setup, the connection configuration and initial styles.

**Lab solution:** [no-frills-php-crud-app commit-1](https://github.com/DanyilT/projects-in-university/tree/69845351e020ae16742682ee33276ecf0b98cb4b)
