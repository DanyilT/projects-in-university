[Module README](../README.md)

## What this week is for

Lab 5 is part 2 of the tutorial: an editable list of all users (using HTTP query strings), modifying an existing user (Update) and deleting entries from the database (Delete). In the module schedule the lab runs in weeks 8 and 9, and the CRUD app is due in week 9. The result is the next commit of the same repository on GitHub, which adds Create, Read, Update and Delete for users, with update.php and update-single.php for updating users, delete.php for deleting them, and links to the new actions in index.php.
