# Week 02 — Lab 2: Gantt chart practical

**Module:** IT Business Management (`COMP H2034`)  
**Semester:** 4 (Year 2), folder `sem04`

[Module README](../README.md)

## What this week is for

Week 2 was time management (MCQ 1). The lab asks each team to share a Trello board for the web server project and the software engineering and testing project, to create a Gantt chart for the design of the software engineering project and the development of the web server project with the weekly plan up to the due dates, to save the file on the Trello board, and to screenshot each stage (design, development and the generated bar chart) into a Word document saved as a PDF for Brightspace. The solution is a Gantt chart with the Design Phase (requirement gathering, database schema design, initial UML diagrams and wireframing), the Development Phase (back end, front end and database implementation) and Testing and Deployment (unit, integration and final testing).
