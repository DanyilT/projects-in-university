# Week 01 — Lab 1: building a small WAN (hardware)

**Module:** WAN Technologies (`COMP H2032`)  
**Semester:** 4 (Year 2), folder `sem04`

[Module README](../README.md)

## What this week is for

Lecture 1 was network security concepts. Lab 1 is a hardware lab, the WAN Technologies two router lab: set up the topology and initialise the devices, configure the local LAN devices (in two pods, Dublin and Galway) and verify connectivity, configure static routes across the WAN, and configure a dynamic routing protocol (OSPFv2) across the WAN. The lab sheet is a large PDF (30 pages, about 73 MB).
