# Week 10 — Lab 10: WAN technologies revision lab (Packet Tracer)

**Module:** WAN Technologies (`COMP H2032`)  
**Semester:** 4 (Year 2), folder `sem04`

[Module README](../README.md)

## What this week is for

Lecture 10 was an introduction to software defined networking. Lab 10 is a Packet Tracer revision activity with marks: configure static NAT (24 marks), configure PAT (31 marks), create standard ACLs (15 marks) and an ACL for remote SSH access (30 marks), on a network with a branch office, a central office and an ISP. The devices are partially configured, and the sheet asks for the ACL rules to be entered in the specified order.
