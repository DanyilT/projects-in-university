# Week 06 — Lab 6: port address translation (Packet Tracer)

**Module:** WAN Technologies (`COMP H2032`)  
**Semester:** 4 (Year 2), folder `sem04`

[Module README](../README.md)

## What this week is for

Lecture 6 was WAN concepts. Lab 6 is a Packet Tracer activity on PAT: configure dynamic NAT with overload, verify it, configure PAT using an interface and verify the PAT interface implementation. The sheet asks for the answers to a quiz on the WAN concepts in Brightspace.
