# Week 06 — Lab 6: physical ERD and classes (version 5.0)

**Module:** Software Engineering and Testing (`COMP H2027`)  
**Semester:** 4 (Year 2), folder `sem04`

[Module README](../README.md)

## What this week is for

Lab 6 creates the physical ERD (the designer view), a conceptual class diagram, and a CRUD connection through an object in PHP (chapter 12 of lecture 6 has sample class code), archived as version 5.0. The solution documents the physical ERD (the users, posts and comments tables) and the conceptual class diagram with the User, Post, Comment and DatabaseConnection classes and their properties and methods. The resources are the lecture 6 code files: a Car class and a page that pulls cars from the database through an object.
