# Week 09 — Lab 9: test planning

**Module:** Software Engineering and Testing (`COMP H2027`)  
**Semester:** 4 (Year 2), folder `sem04`

[Module README](../README.md)

## What this week is for

Lab 9 plans the tests: discuss the sprint and the test plans with the lab supervisor, and upload a PDF with all the test cases. The solution lists the planned test cases for unit testing (the User, Database, Validation and Authentication classes), UI testing (navigation, form submission and feedback, error messages, accessibility, responsive design and browser compatibility), requirements testing, the basis path and equivalence partition calculations, and validation tests.
