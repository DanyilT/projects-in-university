## What this week is for

Lab 7 puts the whole system together as a shippable draft implementation, using the checklist and marking scheme of the third assessment, so that it runs and performs all the CRUD functions; it is archived as version 6.0. The solution is the sprint document: a title page with the links to the GitHub repository and to its versions of 19, 20, 21 and 26 March 2025, which refers to the third assessment for more. The resources are the lecture code files of versions 5.0 and 6.0 (zips of PHP classes).
