# Week 05 — Lab 5: database connection and logical ERD

**Module:** Software Engineering and Testing (`COMP H2027`)  
**Semester:** 4 (Year 2), folder `sem04`

[Module README](../README.md)

## What this week is for

Lab 5 creates the conceptual and the logical ERD from the use case specification (underlining the entities and their data attributes), then the physical ERD and the database, populates it with records, and creates a database connection that tests the CRUD output. The solution is the sprint document with the three ERDs and the link to the version of the code on GitHub.
