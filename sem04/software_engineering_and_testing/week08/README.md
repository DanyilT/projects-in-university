# Week 08 — Lab 8: unit test introduction

**Module:** Software Engineering and Testing (`COMP H2027`)  
**Semester:** 4 (Year 2), folder `sem04`

[Module README](../README.md)

## What this week is for

Lab 8 introduces unit tests: create one unit test file that fully tests an encapsulated class (for a Product class, a UnitTestProduct class that instantiates the object with data), and upload the test PHP class. The solution is a PHPUnit test case for the User class (UserTest) that tests its getters.
