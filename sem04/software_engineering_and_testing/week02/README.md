# Week 02 — Lab 2: daily scrum, version 1.0 of the website and initial requirements

**Module:** Software Engineering and Testing (`COMP H2027`)  
**Semester:** 4 (Year 2), folder `sem04`

[Module README](../README.md)

## What this week is for

From lab 2 every lab has part (a), a daily scrum of 3 to 5 minutes per team (what was done last week, what will be done today and why, and the impediments) with the diary entry, and part (b), a sprint. The sprint of lab 2 is version 1.0 of the website in PHP: a homepage that lists the top 5 best sellers with a for loop, a search page and a product description page, archived as version 1.0 on OneDrive or GitHub. The solution is an initial requirements outline: the scope (in scope: the homepage, the search and product pages, a database connection, basic PHP search and display and a simple interface; out of scope: advanced authentication and authorisation, API integrations and a mobile app), the product requirements, a walkthrough scenario and the system requirements, with the link to the GitHub repository.
