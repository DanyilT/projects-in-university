**Matching project repo:** [tu863-wdss-qwerty-social-network](https://github.com/DanyilT/tu863-wdss-qwerty-social-network) (QWERTY - The Social Network, the project that this module shares with Web Development Server-Side and IT Business Management: the website, with the tests of CA 4)

## What this module is for

Software Engineering and Testing is about the software development process more than the product: a project proposal, requirements and use cases, design with ERDs and class diagrams, a draft implementation in PHP with a MySQL database, and software testing (unit, user interface, validation, basis path, equivalence partition and requirements testing). Every week the team of the project has a lab with a daily scrum, a sprint and a diary entry, and the four assessments follow the stages of the project. The project is shared with Web Development Server-Side (the same brief, grading the PHP and database side) and IT Business Management (project management and the team meetings). The team of two built QWERTY, a social network website in PHP and MySQL; its code is in the tu863-wdss-qwerty-social-network repository on GitHub, which the weekly sprint documents link to. The module is 100% continuous assessment: weekly lab work (20%), the proposal (5%), the requirements document and draft website (20%), the design and draft implementation (20% plus a 5% demo) and software testing (25% plus a 5% demo). This folder has the lab sheets, the project diary and sprint document of each lab, the four assessment briefs with their templates and grading rubrics, the submitted documents and the testing code, and the lecture code files of weeks 4, 6 and 7.

### Module descriptor

**Module aims.**

- To provide students with an appreciation and understanding of the software development lifecycle.
- To provide students with an understanding of structured analysis and design techniques.
- To provide students with an awareness of the different approaches to systems development.
- To provide students with an appreciation of software testing and its role in software quality assurance (SQA).
- To provide students with acute debugging skills through different debugging strategies.

**Indicative syllabus.**

- Beginning a Software Project
- Requirements Analysis
- System Design
- Software Implementation
- Software Testing
- Debugging

**Recommended reading.**

- Sommerville (2004), Software Engineering, 7th edition, Addison Wesley.
- Hawiyszkiewycz (2000), Introduction to Systems Analysis and Design, Prentice Hall.
- G. J. Myers, C. Sandler, T. Badgett and T. M. Thomas (2004), The Art of Software Testing, 2nd edition, Wiley.
- Hunt and Thomas (2003), Pragmatic Unit Testing in Java with JUnit, Pragmatic Bookshelf.

**Supplementary materials.** R. S. Pressman (2000), Software Engineering, 2nd edition, Theory and Practice, Prentice Hall.
