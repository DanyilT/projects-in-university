# Week 02 — Practical 2: learning the Linux command line

**Module:** Operating Systems (`COMP H2014`)  
**Semester:** 4 (Year 2), folder `sem04`

[Module README](../README.md)

## What this week is for

Practical 2 revises and teaches the basic use of the Linux command line in the Konsole terminal with the bash shell: the structure of a command (command, options and arguments), working with files and directories, moving, copying and looking at the contents of files and directories, writing a simple shell script and the manual pages. The reflective activity is a quiz. The resource is a UNIX commands cheat sheet.
