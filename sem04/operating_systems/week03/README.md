# Week 03 — Practical 3: GNU Emacs and C programming

**Module:** Operating Systems (`COMP H2014`)  
**Semester:** 4 (Year 2), folder `sem04`

[Module README](../README.md)

## What this week is for

Practical 3 installs the GNU Emacs editor and works through its guided tour and built-in tutorial (the key sequences to find and save a file, move in a line, undo, split the screen and quit), then covers the anatomy of a C program, an online C tutorial and C exercises: hello.c compiled as sayhi, a loop printer that prints 20 iterations and says Goodbye (written with a loop in main and with a function), a program that stores the squares of 0 to 9 in an array, and one that also adds them up. The journal was written for the session of 27 February 2025, with the Emacs key sequences, the gcc version, three gcc options, the programs and their pseudo-code. The compiled programs are Linux 64-bit executables.
