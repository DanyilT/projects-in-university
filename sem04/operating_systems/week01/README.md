# Week 01 — Practical 1: installing Mageia 8 Linux with VirtualBox

**Module:** Operating Systems (`COMP H2014`)  
**Semester:** 4 (Year 2), folder `sem04`

[Module README](../README.md)

## What this week is for

Practical 1 installs Linux in a virtual machine: download and install Oracle VM VirtualBox with its Extension Pack, download a Mageia 8 64-bit network boot disk, create and configure the virtual machine, give it Internet access, partition the virtual disk, choose the packages to install, set the password of the administrator (root) and add an ordinary user account. During the installation there is an intermission for reading about the project. The lecture was fundamental concepts. The resources are a handout on generating pseudo-random integers and floating-point numbers and a glossary of terminology.
