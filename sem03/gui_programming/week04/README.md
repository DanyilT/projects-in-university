# Week 04 — Event handling (lecture only, no lab)

**Module:** GUI Programming (`COMP H2011`)  
**Semester:** 3 (Year 2), folder `sem03`

[Module README](../README.md)

## What this week is for

Session 4 was the lecture on event handling. There was no lab sheet this week. The folder has the lecture examples: action listeners on buttons, an item listener on check boxes, a list selection listener and window events.
