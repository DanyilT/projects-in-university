## What this module is for

Interactive Multimedia is a Unity game development module. The practical work is the Unity Learn Create with Code course: five units (driving simulation, basic gameplay, sound and effects, gameplay mechanics and user interface), each scheduled for a two-week block with a prototype to build, a challenge to submit and a quiz, plus a lab step for the group project; a sixth unit covers next steps (optimisation, troubleshooting and sharing projects). The lectures cover the course outline, human-computer interaction, submitting work through GitHub, game design, ludology, usability evaluation, the 3D pipeline and digital realities. The module has clinics instead of labs. The grade is the five course units (40%, 8% each), an Alpha submission (20%) and a Beta submission (40%) of a group game project. The solutions of the units are in the Unity-babysitter repository on GitHub, and the group project is in the tu863-imm-webgl-game repository (the alpha and beta branches); both are linked in the files below. This folder has the unit PDFs, the challenge and quiz sheets, the project lab sheets, the unit support files, the project brief and screenshots.

The links to the five course units are in [`CreateWithCode.md`](CreateWithCode.md): the Unity-babysitter repository on GitHub (the Junior-Programmer branch, folder Create with Code), with player control, basic gameplay, sound and effects, gameplay mechanics and user interface.

## Lectures and practical work

The lectures of the module (slides are not in the repository):

1. Course outline
2. HCI (human-computer interaction)
3. GitHub submission method (setting up GitHub and Unity Play)
4. Game design
5. Ludology
6. Usability: evaluation methods
7. 3D pipelines
8. Digital realities

The lecture 7 demo is a button menu in the lecturer's repository, https://github.com/TUD-RSmith/Lecture_Demo (a version of the demo from the lecture on 21 November 2022). The URL in its code is no longer active, but the code works if the URL is changed.

The practical work is divided into 5 units, each scheduled for a 2-week period. The challenge at the end of each unit is uploaded to the submission link before the end of the 2-week block; the challenge is submitted, not the result of the lesson. It is recommended to complete each unit in a single week, which leaves time in the second half of the semester for the project and ensures that the new material is covered before the project work starts. Each practical session begins with a link to learn.unity.com, and a getting started video explains downloading and installing Unity 3D. The Unity Learn pages of the course:

- Getting started: https://learn.unity.com/project/getting-started?courseId=5cf96c41edbc2a2ca6e8810f
- Unit 1, driving simulation: https://learn.unity.com/project/unit-1-driving-simulation?courseId=5cf96c41edbc2a2ca6e8810f
- Unit 2, basic gameplay: https://learn.unity.com/project/unit-2-basic-gameplay?courseId=5cf96c41edbc2a2ca6e8810f
- Unit 3, sound and effects: https://learn.unity.com/project/unit-3-sound-and-effects?courseId=5cf96c41edbc2a2ca6e8810f
- Unit 4, gameplay mechanics: https://learn.unity.com/project/unit-4-gameplay-mechanics?courseId=5cf96c41edbc2a2ca6e8810f
- Unit 5, user interface: https://learn.unity.com/project/unit-5-user-interface?courseId=5cf96c41edbc2a2ca6e8810f
- Unit 6, next steps: https://learn.unity.com/project/unit-6-next-steps?courseId=5cf96c41edbc2a2ca6e8810f
- Next step, the Junior Programmer mission Programming Systems and Architecture (data persistence and the core pillars of object-oriented programming, about 5 hours): https://learn.unity.com/mission/programming-systems-and-architecture?pathwayId=5f7e17e1edbc2a5ec21a20af

Unit 5 of the course uses TextMesh Pro, which caused problems for some students; the module page recommends the standard Unity UI tools instead and points to the tutorial: Introduction to Unity UI, part 1 (https://www.raywenderlich.com/6570-introduction-to-unity-ui-part-1).
