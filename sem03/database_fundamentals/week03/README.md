# Week 03 — Lab 3: entity-relationship diagrams in MySQL Workbench

**Module:** Database Fundamentals (`COMP H1029`)  
**Semester:** 3 (Year 2), folder `sem03`

[Module README](../README.md)

## What this week is for

Lab 3 draws entity-relationship diagrams (ERDs) in MySQL Workbench: first a practice diagram of student and course with a one-to-many and then a many-to-many relationship, then two questions. Question 1 draws four statements about a managing director, a company, sales staff, customers and products. Question 2 draws a bank with departments, managers, employees and projects. The sheet explains the conceptual, logical and physical levels of an ERD and dotted (non-identifying) and solid (identifying) relationships. The lecture was entity-relationship modelling.
