# Week 04 — Lab 3: implement port security (Packet Tracer)

**Module:** LAN Switching and Wireless (`COMP H2015`)  
**Semester:** 3 (Year 2), folder `sem03`

[Module README](../README.md)

## What this week is for

Lecture 4 was LAN security concepts. Lab 3 is a Packet Tracer activity on two switches (S1 and S2), PC-A, PC-B, a web server and a rogue endpoint: configure the basic device settings and test connectivity, configure access control on the switches, secure unused ports and configure port security.
