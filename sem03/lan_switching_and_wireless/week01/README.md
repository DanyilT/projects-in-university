# Week 01 — Lab 0: revision, configure VLANs and trunking (hardware)

**Module:** LAN Switching and Wireless (`COMP H2015`)  
**Semester:** 3 (Year 2), folder `sem03`

[Module README](../README.md)

## What this week is for

Lecture 1 was the module introduction and a revision of last year's networking. Lab 0 is a hardware revision lab on two switches and two PCs: build the network and configure the basic device settings, create VLANs and assign switch ports, maintain the VLAN port assignments and the VLAN database, configure an 802.1Q trunk between the switches, and delete the VLAN database. The lab sheet is the Cisco Networking Academy lab with the TU Dublin logo, and its pages are images. The resource is a help sheet of basic Cisco commands.
