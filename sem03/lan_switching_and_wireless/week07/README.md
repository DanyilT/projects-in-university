# Week 07 — Lab 6: configure a WLAN on the WLC (Packet Tracer)

**Module:** LAN Switching and Wireless (`COMP H2015`)  
**Semester:** 3 (Year 2), folder `sem03`

[Module README](../README.md)

## What this week is for

Lecture 7 was WLAN configuration (the controller-based WLAN). Lab 6 is a Packet Tracer activity with a wireless LAN controller (WLC-1), a lightweight access point (LAP-1), a router, a switch and hosts: monitor the WLC, create a wireless LAN, configure a DHCP scope, and connect a host to the WLAN.
