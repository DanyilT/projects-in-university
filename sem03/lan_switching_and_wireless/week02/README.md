# Week 02 — Lab 1: investigate STP loop prevention (Packet Tracer)

**Module:** LAN Switching and Wireless (`COMP H2015`)  
**Semester:** 3 (Year 2), folder `sem03`

[Module README](../README.md)

## What this week is for

Lecture 2 was Spanning Tree Protocol. Lab 1 is a Packet Tracer activity on a switched network with redundant paths: observe the spanning-tree status and port states on the switches, make S4 the root bridge with spanning-tree vlan 1 root primary, and configure PortFast and BPDU Guard. The sheet asks for the answers to 16 questions in a Moodle quiz that is open only during the lab slot.
