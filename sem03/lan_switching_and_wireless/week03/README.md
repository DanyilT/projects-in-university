# Week 03 — Lab 2: implement EtherChannel (hardware, with a Packet Tracer activity)

**Module:** LAN Switching and Wireless (`COMP H2015`)  
**Semester:** 3 (Year 2), folder `sem03`

[Module README](../README.md)

## What this week is for

Lecture 3 was EtherChannel with LACP and PAgP. Lab 2 is a hardware lab on switches: build the network and configure the basic device settings, create VLANs and assign switch ports, configure 802.1Q trunks between the switches, and implement and verify an EtherChannel between the switches. The Packet Tracer file is the Cisco activity Configure EtherChannel, with basic switch settings, an EtherChannel with Cisco PAgP, an 802.3ad LACP EtherChannel and a redundant EtherChannel link.
