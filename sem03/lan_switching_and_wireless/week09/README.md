# Week 09 — Lab 8: troubleshoot static and default routes (Packet Tracer)

**Module:** LAN Switching and Wireless (`COMP H2015`)  
**Semester:** 3 (Year 2), folder `sem03`

[Module README](../README.md)

## What this week is for

Lecture 9 was troubleshooting static and default routes. Lab 8 is a Packet Tracer activity: a technician has pre-configured a topology of four routers and three LANs but the LANs cannot reach each other, and the task is to find and correct the errors in the IPv4 static and default routes.
