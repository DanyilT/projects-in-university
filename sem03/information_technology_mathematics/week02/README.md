# Week 02 — Tutorial 2: trees

**Module:** Information Technology Mathematics (`COMP H2026`)  
**Semester:** 3 (Year 2), folder `sem03`

[Module README](../README.md)

## What this week is for

Lecture 2 was trees and tutorial 2 practises them in seven questions: which graphs are not trees, the weight matrix of a weighted graph, minimal spanning trees with Prim's algorithm, rooted trees and binary trees, and questions about a rooted tree (root, children, parent, leaf nodes and subtrees). The sheet is a scan, and question 8 has its diagram as a separate image. The folder has the sheet, the diagram, the lecturer's sample solutions and the lecture review questions.
