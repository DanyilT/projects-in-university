# Week 08 — Tutorial 6: matrices, part 1, and CA 1

**Module:** Information Technology Mathematics (`COMP H2026`)  
**Semester:** 3 (Year 2), folder `sem03`

[Module README](../README.md)

## What this week is for

Lecture 7 was matrices, part 1. The tutorial covers the rank (size) of a matrix, the elements of a matrix and matrix arithmetic. CA 1 (20%) was in this week: a 90-minute test with mixed question types. Its instructions were to attempt all questions in one attempt and to hand in written work showing how each calculation was solved, because no marks are given for the final result without it. The folder has the tutorial sheet, an overview of it and the lecturer's sample solutions.
